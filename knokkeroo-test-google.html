Beta (v4) status

Closed testing track exists — invite-only for now

A v4.19.0 build (Home Screen widget, favourites, notifications) is on Google Play's closed testing "Alpha" track, submitted for Google's review 30 July. It's not self-serve yet — the tester list is a small, specific set of Google account emails, not an open link. To be added: email hello@knokkeroo.com with the Gmail address you want added, then once confirmed, opt in at play.google.com/apps/testing/com.goliontus.knokker and install via the same link as the production app above.
