knokkeroo for iPhone

Two ways to run knokkeroo on iPhone: the live public app, or the newer TestFlight beta. Pick one below, then find test scenarios and how to report bugs further down.

Option A — Live public app

Live now, public

knokkeroo is publicly live on the App Store — no TestFlight or sign-up needed. Just search "knokkeroo" or use the button below.

Option B — TestFlight beta (newer features)

Beta — build 4.21.0 (28)

The beta includes features not yet on the public App Store: the Home Screen widget, a Home Screen quick action, Apple Watch companion, and Apple TV pairing.

Register

  1. Install TestFlight from the App Store if you don't already have it.
  2. Open testflight.apple.com/join/XaabanK9 on your iPhone.
  3. Tap Accept, then Install.

Install

TestFlight installs knokkeroo (build 4.21.0 / 28) automatically once you accept the invite above — open it from TestFlight or your Home Screen.

What to test

Core flows (test on either option):

  • Registration / login (verification code)
  • Contacts screen — status colours (green/amber/red)
  • Sending and accepting a connection request
  • knok (checking in) and seeing your own time update
  • Quiet hours settings
  • Account deletion

Beta-only (Option B):

  • Home Screen quick action (long-press app icon → "knok now")
  • Home Screen widget (own status + favourite contact's dot)
  • Pairing an Apple Watch or Apple TV (see their pages via the Apple devices page)

Full ISO-format test case document (fillable steps, test data, expected/actual result columns) — for both the core flows above and the Apple Watch / Apple TV companion scenarios: Download test plan (.docx)

Report a bug

Email hello@knokkeroo.com with what you did, what you expected, and what actually happened. If you're working from the downloadable test plan, include the test case ID (e.g. "IP-3") in the subject line.
