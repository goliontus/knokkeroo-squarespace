knokkeroo for Huawei

Live now

knokkeroo is available today on the Huawei AppGallery, completely free.

How to install it

There is nothing to join and nobody to email — knokkeroo is public on the AppGallery, so you can install it right now.

  1. On your Huawei phone, open AppGallery.
  2. Tap the search box and type knokkeroo.
  3. Tap Install. It is free, with every feature included — there is no paid tier on Huawei at all.

Or tap the Explore it on AppGallery button above on the phone itself, which opens the listing directly.

Then open the app and sign in: enter your mobile number, wait for the verification code by message, and type it in. That is the whole setup.

Beta (v4) status

Not yet available

A v4 build for Huawei exists and is uploaded to the AppGallery, but there is no way to join a Huawei beta yet. Unlike Apple and Google, the AppGallery has no self-service testing track we can open — Huawei's Open Testing has to be set up by hand and every tester needs a Huawei ID. Until that is arranged, everything below applies to the live production build — which is the one you just installed, so there is nothing you need to do differently and nothing you need to ask us. This page will change when a Huawei beta becomes possible.

What to test

  • Contacts screen — status colours (green/amber/red)
